# 上班鼓励器 · 工时银行

> 把投入的时间，认真记一笔。

一个离线运行的 Windows 桌面小工具。参考[《审计狗新增“工时系统”》](https://mp.weixin.qq.com/s/CyuDUOO4P2cO7Ty-wK6IwQ)的思路，它根据实际记录的键鼠活跃时间展示「赚到」参考金额，不再把加班时间虚算成额外工资。

**显示的金额是按设置折算的参考值，不是实际工资或加班费；折算的调休天数也不代表实际享有的假期。**

## 运行方式

### 单文件 EXE（推荐日常使用）

双击 `上班鼓励器.exe` 即可，无需安装、无需管理员权限。首次运行会把界面、桌宠源码和素材释放到：

```text
%LOCALAPPDATA%\上班鼓励器\
```

账本也保存在这里：

```text
%LOCALAPPDATA%\上班鼓励器\workbank.json
%LOCALAPPDATA%\上班鼓励器\workbank.json.bak
```

升级时只需替换 EXE；程序文件会按内嵌版本更新，`workbank.json`、备份和 `assets\custom-character.png` 不会被覆盖。重复双击不会启动第二份程序，而是尝试把已有窗口带到前台；即使工时卡片已收进托盘，也会尝试将它恢复。若 EXE 同目录放着旧的 `workbank.json`，首次启动会询问是否导入；也可以手动执行：

```bat
上班鼓励器.exe --import "D:\旧目录\workbank.json"
上班鼓励器.exe --data
```

`--data` 打开账本目录，`--help` 查看全部参数。若要把账本放到 U 盘或指定目录，可用 `--data-dir "D:\工时数据"`，或设置环境变量 `WORKENCOURAGER_DATA_DIR`。卸载时先备份账本，关闭程序后删除 `%LOCALAPPDATA%\上班鼓励器` 即可；程序不写注册表，登录启动只在当前用户的「启动」文件夹创建快捷方式（见下文）。

未签名的 EXE 首次运行可能触发 Windows SmartScreen；这是本地程序，不联网。若从网盘或邮件获得，可先右键文件 → 属性 → 解除锁定。

### 直接运行 HTA / 解压 ZIP

双击 `上班鼓励器.hta`，桌面会出现小鲸角色；首次运行时设置窗口保持显示。此时数据保存在 HTA 所在目录，适合放在固定文件夹或 U 盘中使用。ZIP 便携版即采用这种方式。

## 开始使用

1. 双击 `上班鼓励器.exe`（单文件版）或 `上班鼓励器.hta`（直接运行版），桌面会出现小鲸角色；首次运行时设置窗口保持显示。
2. 填写税后到手月薪，选择「月薪 ÷ 月计划工时」或「月薪 ÷ 本月计薪天数」。按工时模式填写月 / 日计划工时；按天模式填写本月计薪天数和每周班次，必要时添加单日例外。
3. 首次保存后自动开始记录。之后有两个独立选项：①「登录 Windows 后启动程序」默认关闭，只在当前用户登录时打开 HTA；②「打开程序后自动开始记录」默认关闭，打开程序后才开始采样。启动期间、休眠及程序关闭时均不补算。
4. 单击小鲸可以展开或收起工时卡片；卡片会贴着小鲸出现，拖动小鲸时卡片跟着移动。收起后卡片不占任务栏，**小鲸仍留在桌面，已开始的记录会继续**。桌宠运行时，系统托盘中有上班鼓励器图标；双击图标或右键选择「显示工时银行」可重新打开卡片。图标可能位于 Windows 右下角 `^` 的隐藏图标区域。展开时程序会尝试将卡片移到前台；如果 Windows 阻止抢焦点，任务栏按钮会闪烁，可点击任务栏找回。
5. 右键小鲸可以开始 / 暂停记录、切换小鲸置顶或退出程序；也可右键托盘图标选择「退出工时银行」。只有选择退出才真正结束程序；桌宠启动失败或异常退出时，卡片和系统关闭控件会恢复。桌宠运行时，卡片标题栏不显示最小化和关闭按钮。
6. 卡片右上角的「收起」按钮会隐藏卡片、只留下小鲸（同 `Alt+H`，需要桌宠在运行）；「置顶窗口」控制的是**卡片本身**。小鲸置顶在右键菜单中单独控制，开启后程序会定期让桌宠重新置顶，减少被浏览器、聊天窗口等遮住；全屏独占程序仍可能覆盖它。小鲸默认置顶、卡片默认不置顶；设置保存后会记住各自选择和小鲸位置。
7. 卡片收起时，小鲸旁的简要信息卡可设为「常显」「仅悬停」或「关闭」。小卡顶部可一键切换常显 / 悬停及开始 / 暂停记录；右键小鲸可在三种显示模式间切换，即使小卡关闭也能恢复。点击金额区域可打码，点其他区域展开主卡，右键小卡打开小鲸菜单。
8. 「查看记录」提供按月切换的每日活跃工时柱条和明细表。「手动补记」可按日期添加会议、阅读或其他时间，并删除错误条目；补记单独列示，**不计入活跃工时、赚到金额或加班**。
9. 卡片右上角的「换肤」会弹出主题菜单，可直接选择深海蓝、围裙纸或海雾玻璃。三款主题都可以在设置页用「窗口透明度」滑杆调整（60%–100%），并分别记住各自的值；深海蓝和围裙纸默认 100%（不透明），海雾玻璃默认 82%。透明度作用于**整个窗口**，数值越低越能透出后面的桌面，过低时文字可读性会下降。海雾玻璃使用深色半透明配色；窗口透明时系统标题栏可能保持系统配色，切回不透明后深海蓝和围裙纸的标题栏、边框会继续跟随主题着色。
10. 直接点击卡片上的今日赚到金额或本月累计金额，可以临时显示或隐藏金额；这个切换不会改变「默认隐藏金额」设置，并会同步到桌宠信息卡、历史记录和工单。
11. 进度条会随投入升温：未到计划工时时，按冷 / 暖 / 热阶段出现不同速度的缓慢扫光；达到或超过计划工时（含休息日加班）后，整条进度条呈现白热核心，上下边缘跳动不规则电弧和软火苗，并伴随少量余烬；暂停记录、采样未就绪或键鼠空闲时转为低饱和钢蓝，配合霜斑、冰裂纹和贴合已填充部分的霜电弧，恢复记录后继续。桌宠旁的简要信息卡会同步显示这些状态。

| 设置 | 默认值 | 说明 |

快捷键：

| 按键 | 功能 |
| --- | --- |
| `Esc` | 关闭当前弹窗；设置页未保存的改动会还原 |
| `Alt+M` | 显示 / 隐藏金额 |
| `Alt+T` | 开始 / 暂停记录 |

窗口以 530 × 720 的紧凑尺寸出现在桌面右侧，卡片内容在常规屏幕上可完整显示；屏幕空间不足时，页面和设置窗口仍可滚动。从桌宠打开卡片时，它会优先贴在鲸鱼左侧（空间不足时放右侧），并与小鲸的底边对齐；小鲸移动后卡片会跟随。三款主题都使用整个窗口的透明度，数值越低越能透出后面的桌面；透明效果依赖 PowerShell 和系统合成支持，失败时会保留可读的同色背景并给出提示。未保存班表时切换置顶和拖动位置仅在本次运行中生效，之后保存班表会一并保存这些选择。

内置形象采用鲸鱼娘插画素材，来源为 [vlln/whale-girl](https://github.com/vlln/whale-girl)（仓库标注 MIT；角色形象由 [ZipZipPipe](https://space.bilibili.com/4168597) 创作，项目在 README 中致谢）。这不是 DeepSeek 官方形象。素材经裁切、等比缩放和透明边缘处理，包含待机、眨眼、挥手、庆祝、努力和冲刺姿态；奋斗姿态基于庆祝帧重新绘制了笑容、咖啡杯和小星星。卡片头像从站姿帧裁出；未使用原项目的动画播放器。发布或商用前请同时核实角色设定与原作者的授权范围。

今日赚到显示四位小数，月度汇总和工单显示两位小数；金额达到日计划上限后停止增加。点击今日赚到或本月累计金额可临时切换打码；简要信息卡上只有金额区域负责切换，点击其他区域仍会展开完整卡片。能量条按活跃工时进度由青蓝变为橙红，加班时满格；暂停或键鼠空闲时变暗并停止流动。0–59% 是带缓慢呼吸、漂浮冷光和前缘信标的深海蓝；60–89% 转为暖铜色并出现边缘热光；90–99% 加深为橙琥珀并出现少量上升火星；暂停或空闲时冻结成带霜斑、裂纹和霜弧的钢蓝。桌宠小卡同步显示这些阶段效果，并在冻结/燃烧时给整张小卡加上冷色或暖色描边。完整卡片收起时，小鲸在 50%–90% 显示努力姿态，90% 起显示冲刺姿态；进入加班后先显示握拳拿咖啡的奋斗姿态，**当日累计活跃加班满 2 小时**后改为平静的 working 姿态。切换到奋斗姿态时会轻跳约 4 秒，之后保持静止；关闭动画后不轻跳。暂停、键鼠空闲时仍显示对应的普通姿态，恢复后按照当天累计加班时长选择；第二天重新计算。若已过计划下班时间但活跃工时还未达到日计划，累计加班仍为 0，奋斗姿态会继续显示。收工时短暂庆祝，卡片展开时优先挥手。悬停在小鲸上可看到当前状态和今日赚到（默认打码）。进度走过 50%、90% 和 100% 时各提示一次。金额可选在显示 30 / 60 秒后自动打码，不改变启动时的默认隐私设置。休息提醒只按程序实际累计的活跃时长触发，暂停、键鼠空闲和锁屏期间不增长；稍后提醒以再记录 15 分钟活跃时间为准。计数只在本次运行周期内，程序重启后从零开始。

卡片底部会根据今日赚到显示下一个还没达到的小目标：签字笔、地铁、早餐、冰美式、零食、外卖、午饭、奶茶、电影、小书、小火锅，随后是半天、四分之三天和一天房租。每次越过一个目标，桌宠会提示「目标名，赚到了 ✓」，每个目标每天只提示一次；自定义目标同样生效。房租目标按到手月薪折算（月薪 ÷ 60、÷ 40、÷ 30），会随工资缩放；到达当天计额上限后不再显示具体目标。如果这些目标不合适，可在设置页的「自定义目标」里每行填写「名称=金额」，名称最多 12 个字、最多读取 20 项；程序会按金额排序并忽略无法解析的行，留空或有效项不足 3 个时使用内置目标。

### 使用自己的角色图片

关闭程序后，将具有透明背景的 PNG 放到 `assets/custom-character.png`，再次打开程序即可使用。自定义图片会保持长宽比例，作为静态形象显示；原有内置形象及表情帧仍会保留。删除或移走自定义图片后会恢复内置形象；如果图片无法读取，也会自动回退。建议使用竖幅图片；如用于公开分发，请先确认素材的使用授权。

## 工时和金额怎么算

### 方式一：按月计划工时（原有方式）

```text
参考时薪 = 到手月薪 ÷ 月计划工时
今日赚到 = min(今日活跃工时, 日计划工时) × 参考时薪
```

例如到手月薪 8,000 元、月计划 174 小时、每天计划 8 小时，参考时薪约为 45.9770 元；活跃 8 小时后，当日赚到封顶约 367.82 元。

### 方式二：按月计薪天数

```text
计薪日参考金额 = 到手月薪 ÷ 本月计薪天数
当天参考时薪 = 计薪日参考金额 ÷ 当天计划工时
今日赚到 = min(今日活跃工时, 当天计划工时) × 当天参考时薪
```

例如到手月薪 8,000 元、本月计薪 20 天，则计薪日参考金额为 400 元：当天计划 8 小时，参考时薪是 50 元；计划 6 小时，参考时薪约 66.67 元。两个计薪日达到各自计划工时后都以 **400 元封顶**。不论哪种模式，加班只记录时间，不额外增加金额。

在设置页可按周一到周日填写计划工时，0 表示休息日。要设置今天或未来某天的补班、短班或休息日，在「单日例外」填写日期和小时，点击「添加 / 更新例外」，再点击「保存设置」；对同一日期点击「恢复周模板」可取消例外，保存后生效。计划工时为 **0 的休息日**赚到金额为 0，记录到的全部活跃时间单独记为加班。如果实际补班并希望按计薪日计算，须将该日计划改为大于 0 的时长。

计薪天数**按月单独填写**，可在设置页同时预填下个月。切换模式或改变当天计划时，会提示确认并重算当天已有赚到金额 / 加班；前一天及更早的记录保留各自的历史快照。如果当月天数尚未填写，程序会暂停记录并提示设置；不会猜测或沿用上月天数，设置后需手动重新开始记录。

两种方式的月度赚到金额都是该月每日记录的金额之和，不会自动按月薪或计薪天数补满，也没有月度金额上限。如果实际计薪工作日数量与输入的月计薪天数不一致，即便每天完成计划，月累计也可能不等于月薪。

### 加班与调休参考

```text
当日加班 = max(0, 今日活跃工时 − 当天计划工时)
本月折合调休标准日 = 本月每日加班之和 ÷ 8 小时
```

卡片上的「标准日」固定按 8 小时折算；加班和调休只是参考记录。到达计划下班时间后，状态可能显示「加班中」，但只有当**活跃工时超过当天计划工时**时，加班时长才会增加。

### 活跃时长的边界

- 程序读取 Windows 系统的最后键鼠输入时间：最近 2 分钟内有输入时视为活跃；这包含最后一次输入后的最多 2 分钟。
- 统计的是整台电脑上的键鼠输入，不记录具体按键、鼠标位置或输入内容，也**不能判断操作是否与工作有关**。处理个人事务时请暂停记录。
- 开会、阅读纸质资料等没有键鼠输入的工作，2 分钟后可能不计入；因此活跃时长不等于在岗时长。手动补记可作为独立备注，不会填补或改写采样记录，也不会增加金额和加班。可补记今天及以前的日期，单条为 1–1440 分钟的整数，同日补记合计不超过 1440 分钟；错误条目可删除后重新填写。补记时间可能与键鼠活跃时间重叠，不宜直接相加视为总工时。
- 只有程序运行且开启记录时才统计。程序关闭、电脑休眠、采样不可用或刷新中断较长时间时不补算，可能少记少量时间。
- 卡片、月度汇总、历史记录及工单均使用本机数据；没有云同步。鼠标悬停在卡片和小鲸上可查看简短状态。「查看记录」可主动选择位置导出完整 JSON 备份或 CSV；JSON 含薪资设置，CSV 为 Excel 可读的 UTF-16LE 日明细，含每日金额与计算用时薪；为兼容既有表格和脚本，金额列名仍为「当日投入（元）」。导出前会确认，只创建新文件、不覆盖已有文件，也不能指向正在使用的账本。

## 运行环境与隐私

- Windows 10 / 11（已在 Windows 11 验证）；Windows 7 需安装 IE 11 及系统组件，尚未实测。
- 使用系统自带的 `mshta.exe` 打开，无需单独安装应用或手动构建；直接运行 HTA 时，请保持 `DesktopPet.cs` 和 `assets` 文件夹与 HTA 放在一起。EXE 版会自动释放并维护这些文件。
- 桌宠通过 Windows PowerShell 和系统 .NET 在本机启动透明窗口；首次加载需要短暂编译组件。工时采样使用 `GetLastInputInfo`，卡片置顶使用 `SetWindowPos`，Windows 锁屏检测使用当前会话的 WTS 通知；登录启动只使用当前用户「启动」文件夹的快捷方式，默认不创建。锁屏保护开启但桌宠连接或 WTS 通知不可用时，程序暂停记录并提示，不会假装锁屏监控正常。标题栏着色使用 Windows 11 的 DWM 属性；三款主题的窗口透明度使用分层窗口的整体 alpha（100% 时移除透明层）。桌宠与卡片只通过临时文件交换状态和操作；悬停状态默认只含打码金额。
- 如果 PowerShell、HTA、.NET 动态编译或系统策略阻止桌宠启动，卡片会保留并显示「重试桌宠」；采样失败时**不会按经过时间冒算工时**。所有操作均不联网、不上传，也不记录输入内容。
- 桌宠形象来自第三方开源项目的鲸鱼娘插画（仓库标注 MIT），角色原设定作者为 ZipZipPipe；本项目对素材做了裁切和缩放，详见 `assets/character-design.md`。如计划传播或商用，请先核实角色与素材的授权。

直接运行 HTA 时，数据保存在 HTA 所在目录；EXE 版保存在 `%LOCALAPPDATA%\上班鼓励器\`。该目录需要写入权限：

| 文件 | 用途 |
| --- | --- |
| `workbank.json` | 设置及每日记录，包含月薪，请妥善保管 |
| `workbank.json.bak` | 上一次成功保存时的备份，同样包含敏感数据 |
| `workbank.json.tmp` | 保存过程中的临时文件 |

主文件损坏时程序会尝试读取备份；如果主文件和备份均无法读取，会停止保存并提示，避免覆盖原数据。更换电脑时可在关闭程序后复制主文件及备份。若需完全重置，请在确认无需保留数据后同时处理主文件和备份。

旧版的 `workhistory.json` 和 `workstate.json` 不会被删除或导入：旧版按班次推算并计算加班费，与本版活跃工时口径不同，因此不会混入新的统计，旧记录也不会显示在新版记录列表中。

## 开发验证

程序本身不依赖 Node.js。开发时可用 Node.js 18 或更高版本运行计算、隐私和本地文件恢复测试：

```sh
node --test tests/*.test.js
```

构建单文件 EXE（使用 Windows 自带的 .NET Framework 4.x 编译器）：

```sh
node tools/build-exe.js
```

输出为 `dist\上班鼓励器.exe`，`dist/` 不纳入版本库。启动器源码在 `tools/Launcher.cs`；它只负责释放内嵌的 HTA、桌宠源码和素材，并调用系统 `mshta.exe`，不改变账本逻辑。

主程序采用 HTML、CSS 和 ES5 JavaScript，以兼容 Windows HTA 使用的 IE 内核。
