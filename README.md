# 上班鼓励器 · 工时银行

> 把投入的时间，认真记一笔。

一个离线运行的 Windows 桌面小工具。参考[《审计狗新增“工时系统”》](https://mp.weixin.qq.com/s/CyuDUOO4P2cO7Ty-wK6IwQ)的思路，它按实际记录的键鼠活跃时间展示投入，不再把加班时间虚算成额外工资。

**显示的金额是按设置折算的参考值，不是实际工资或加班费；折算的调休天数也不代表实际享有的假期。**

## 开始使用

1. 双击 `上班鼓励器.hta`，桌面会出现小鲸角色；首次运行后，单击小鲸打开设置窗口。
2. 填写税后到手月薪，确认月计划工时、日计划工时和计划下班时间。
3. 保存后自动开始记录。关闭程序再打开时，点击「开始记录」才会继续；关闭期间不会补算。
4. 单击小鲸可以展开或收起工时卡片；卡片会贴着小鲸出现，拖动小鲸时卡片跟着移动，超出屏幕时会自动收进当前屏幕的工作区。收起不会结束程序，**已开始的记录会继续**。按住小鲸可拖动位置。
5. 右键小鲸可以开始 / 暂停记录、切换小鲸置顶或退出程序。退出前会保存当前记录；点击「今日收工 · 签章」也会暂停记录并显示工单。
6. 卡片右上角的「置顶窗口」控制的是**卡片本身**；小鲸置顶在右键菜单中单独控制。小鲸默认置顶、卡片默认不置顶；设置保存后会记住各自选择和小鲸位置。
7. 卡片收起时，小鲸旁会出现一张简要信息卡，显示今日投入、活跃工时和进度条；点击信息卡可以直接展开完整卡片。它只在小鲸旁显示，不占任务栏，也可以在设置中关闭。
8. 卡片右上角的「换肤」在深海蓝与米白围裙纸两种风格之间切换，也可以在设置页选择；选择会随班表一起保存。两种主题使用同一套排版，只更换配色与纸面质感；Windows 11 下标题栏和边框也会跟随主题着色。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 到手月薪 | 需填写 | 扣除五险一金和个税后的金额 |
| 月计划工时 | 174 小时 | 用于计算小时单价，可按实际班表调整 |
| 日计划工时 | 8 小时 | 每日计额上限，以及计算加班的门槛 |
| 计划下班时间 | 18:00 | 只影响倒计时和状态提示，不直接决定加班时长 |
| 默认隐藏金额 | 开启 | 卡片、悬停提示、记录及工单均打码；可临时点击「显示金额」 |
| 整点提醒 | 开启 | 面板打开时显示提示，收起时由小鲸显示不含金额的提示 |
| 桌宠简要信息 | 开启 | 卡片收起时，在桌宠旁显示今日投入和进度，点击可展开卡片 |
| 界面风格 | 深海蓝 | 可切换米白围裙纸；只影响配色，不影响记录 |
| 自定义目标 | 留空 | 每行「名称=金额」，至少 3 项生效；留空使用内置目标 |
| 火焰与小鲸动画 | 开启 | 可在设置中关闭火焰流动与小鲸眨眼 |

设置页的月薪输入框默认隐藏，可单独勾选显示。更改薪资或计划工时会重新计算**当天**的投入和加班，此前各日保留当时的计算口径。

窗口以 530 × 720 的紧凑尺寸出现在桌面右侧，卡片内容在常规屏幕上可完整显示；屏幕空间不足时，页面和设置窗口仍可滚动。从桌宠打开卡片时，它会优先贴在鲸鱼左侧（空间不足时放右侧），并与小鲸的底边对齐；小鲸移动后卡片会跟随。未保存班表时切换置顶和拖动位置仅在本次运行中生效，之后保存班表会一并保存这些选择。

内置形象采用鲸鱼娘插画素材，来源为 [vlln/whale-girl](https://github.com/vlln/whale-girl)（仓库标注 MIT；角色形象由 [ZipZipPipe](https://space.bilibili.com/4168597) 创作，项目在 README 中致谢）。这不是 DeepSeek 官方形象。素材经裁切、等比缩放和透明边缘处理，保留待机、眨眼、疲惫、挥手和庆祝五种姿态，并从站姿帧裁出卡片头像；未使用原项目的动画播放器。发布或商用前请同时核实角色设定与原作者的授权范围。

今日投入显示四位小数，月度汇总和工单显示两位小数；金额达到日计划上限后停止增加。能量条按活跃工时进度由青蓝变为橙红，加班时满格；暂停或键鼠空闲时变暗并停止流动。内置小鲸在接近计划工时时眨眼更频繁，加班时显示疲惫表情；卡片展开时挥手，点击「今日收工 · 签章」后会庆祝片刻。悬停在小鲸上可看到当前状态和今日投入（默认打码）。进度走过 50%、90% 和 100% 时各提示一次。

卡片底部会根据今日投入显示下一个还没达到的小目标：签字笔、地铁、早餐、冰美式、零食、外卖、午饭、奶茶、电影、小书、小火锅，随后是半天、四分之三天和一天房租。房租目标按到手月薪折算（月薪 ÷ 60、÷ 40、÷ 30），会随工资缩放；到达当天计额上限后不再显示具体目标。如果这些目标不合适，可在设置页的「自定义目标」里每行填写「名称=金额」，名称最多 12 个字、最多读取 20 项；程序会按金额排序并忽略无法解析的行，留空或有效项不足 3 个时使用内置目标。

### 使用自己的角色图片

关闭程序后，将具有透明背景的 PNG 放到 `assets/custom-character.png`，再次打开程序即可使用。自定义图片会保持长宽比例，作为静态形象显示；原有内置形象及表情帧仍会保留。删除或移走自定义图片后会恢复内置形象；如果图片无法读取，也会自动回退。建议使用竖幅图片；如用于公开分发，请先确认素材的使用授权。

## 工时和金额怎么算

```text
小时单价 = 到手月薪 ÷ 月计划工时
今日投入 = min(今日活跃工时, 日计划工时) × 小时单价
当日加班 = max(0, 今日活跃工时 − 日计划工时)
本月折合调休标准日 = 本月每日加班之和 ÷ 8 小时
```

例如，到手月薪 8,000 元、月计划 174 小时、日计划 8 小时：活跃 8 小时的投入约为 367.82 元；活跃 9.2 小时时投入仍为 367.82 元，另外记录 1.2 小时加班。月度投入是当月各日封顶金额之和，只包含实际记录的日期，不会按满勤补算。

卡片上的「标准日」固定按 8 小时折算；加班和调休只是参考记录。到达计划下班时间后，状态可能显示「加班中」，但只有当**活跃工时超过日计划工时**时，加班时长才会增加。

### 活跃时长的边界

- 程序读取 Windows 系统的最后键鼠输入时间：最近 2 分钟内有输入时视为活跃；这包含最后一次输入后的最多 2 分钟。
- 统计的是整台电脑上的键鼠输入，不记录具体按键、鼠标位置或输入内容，也**不能判断操作是否与工作有关**。处理个人事务时请暂停记录。
- 开会、阅读纸质资料等没有键鼠输入的工作，2 分钟后可能不计入；因此活跃时长不等于在岗时长。
- 只有程序运行且开启记录时才统计。程序关闭、电脑休眠、采样不可用或刷新中断较长时间时不补算，可能少记少量时间。
- 卡片、月度汇总、历史记录及工单均使用本机数据；目前没有云同步或月度导出功能。鼠标悬停在卡片和小鲸上可查看简短状态。

## 运行环境与隐私

- Windows 10 / 11（已在 Windows 11 验证）；Windows 7 需安装 IE 11 及系统组件，尚未实测。
- 使用系统自带的 `mshta.exe` 打开，无需单独安装应用或手动构建；请保持 `DesktopPet.cs` 和 `assets` 文件夹与 HTA 放在一起。
- 桌宠通过 Windows PowerShell 和系统 .NET 在本机启动透明窗口；首次加载需要短暂编译组件。工时采样使用 `GetLastInputInfo`，卡片置顶使用 `SetWindowPos`，标题栏着色使用 Windows 11 的 DWM 属性。桌宠与卡片只通过临时文件交换状态和操作；用于悬停提示和简要信息卡的临时状态文字默认只含打码金额，只有主动「显示金额」后才会包含真实数值，临时文件会在退出时清理。
- 如果 PowerShell、HTA、.NET 动态编译或系统策略阻止桌宠启动，卡片会保留并显示「重试桌宠」；采样失败时**不会按经过时间冒算工时**。所有操作均不联网、不上传，也不记录输入内容。
- 桌宠形象来自第三方开源项目的鲸鱼娘插画（仓库标注 MIT），角色原设定作者为 ZipZipPipe；本项目对素材做了裁切和缩放，详见 `assets/character-design.md`。如计划传播或商用，请先核实角色与素材的授权。

数据保存在 HTA 所在目录，因此该目录需要写入权限：

| 文件 | 用途 |
| --- | --- |
| `workbank.json` | 设置及每日记录，包含月薪，请妥善保管 |
| `workbank.json.bak` | 上一次成功保存时的备份，同样包含敏感数据 |
| `workbank.json.tmp` | 保存过程中的临时文件 |

主文件损坏时程序会尝试读取备份；如果主文件和备份均无法读取，会停止保存并提示，避免覆盖原数据。更换电脑时可在关闭程序后复制主文件及备份。若需完全重置，请在确认无需保留数据后同时处理主文件和备份。

旧版的 `workhistory.json` 和 `workstate.json` 不会被删除或导入：旧版按班次推算并计算加班费，与本版活跃工时口径不同，因此不会混入新的统计，旧记录也不会显示在新版记录列表中。

## 开发验证

程序本身不依赖 Node.js。开发时可用 Node.js 18 或更高版本运行计算、隐私和本地文件恢复测试：

```sh
node --test tests/*.test.js
```

主程序采用 HTML、CSS 和 ES5 JavaScript，以兼容 Windows HTA 使用的 IE 内核。
